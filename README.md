# MX Countdown ✦

A premium, fully responsive countdown to **March 4, 2027**, 00:00 **Asia/Baghdad (UTC+03:00)**.

## Features

- Live countdown: months, weeks, days, hours, minutes and seconds.
- Calendar-accurate month/week/day calculation.
- Elegant dark and gold design, smooth number animations.
- Layouts for desktop, tablet, and mobile.
- Baghdad clock, calendar days remaining, progress bar.
- No build steps, frameworks, external scripts, or external assets.
- Accessible timer and reduced-motion support.

## Publish with GitHub Pages

1. Open this repository's **Settings** tab.
2. In the sidebar, choose **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Your website will be available at **https://mazenmix.github.io/timer/** after GitHub finishes publishing.

All site code lives in [index.html](index.html). To change the date, update the `TARGET` UTC instant and the labels in that file.
